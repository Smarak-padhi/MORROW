# Product Requirements

## Goal
Deliver a complete mobile-first original-character interactive portfolio for Morrow. Visitors must learn who Morrow is, what Morrow makes (three playable inventions), and how Morrow grows across the story.

## Core scope
Original character sheet; workshop introduction; three playable projects (Shadow Stitcher, Weather Loom, Impossible Clock); interactive scroll-driven story; one immersive interaction; responsive mobile; Easter egg; replay; sound mute if sound exists.

## Quality bar
Every button works, no story dead ends, no console errors, keyboard and touch operable, legible text, graceful reduced motion, clean credits, no unlicensed art. Avoid walls of text; keep scenes under 150 words.

## Release priority
P0 complete narrative and mobile puzzles; P1 layered map and audio; P2 cinematics, guestbook and 3D. Defer P2 when time-constrained.
