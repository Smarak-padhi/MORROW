# MORROW — The Almost-Right Adventure

A mobile-first, interactive storybook portfolio for an original Stitchling character. Track 2 of Baby's First Website (haX.baby), 17–19 October 2026.

## Source of truth

Start with `AGENTS.md`, then `docs/DESIGN_SYSTEM.md`, `docs/PRD.md`, `docs/TRD.md`, `docs/STORY_BIBLE.md`, `docs/EXECUTION_LOOPS.md`, and `docs/LOOP_LOG.md`.

## Build policy

Lock the design system and original character silhouette before producing any final assets. Build one reusable tap-first stitching mechanic across the three portfolio projects; every game must work on mobile. Cinematics are optional enhancements with poster/skip/reduced-motion fallbacks.

## Project status

L00 bootstrap in progress. App not yet verified. Do not treat this README as a claim of completion.
