# Morrow: The Almost-Right Adventure
Mobile-first interactive storybook and original-character portfolio for haX.baby Track 2.

## Run
```bash
npm install
npm run dev
npm run build
```

## Status
This is a **functional vertical-slice prototype**, not the finished game. Includes a locked design token system, original SVG character silhouette, interactive chapter map, story dialogues, shared stitch mini-game, progress saved in localStorage, mute switch, and responsive layout. The other chapters are narrative prototypes, not complete independent puzzles. No AI videos are included yet.
