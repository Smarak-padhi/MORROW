# MORROW — Agent Operating Contract

Read this file first. Then read README.md, docs/DESIGN_SYSTEM.md, docs/STORY_BIBLE.md, docs/PRD.md, docs/TRD.md, docs/EXECUTION_LOOPS.md, docs/LOOP_LOG.md and docs/SKILLS_ADOPTION.md before changing behavior.

## Non-negotiable
- Preserve the original Stitchling silhouette; do not produce a Disney-like fox.
- Lock fonts, tokens and artwork language before implementing final scenes.
- Story canon: Morrow, Sir Clack, Pipkin, Professor Primrose Perfect, the Unfinished One. Three connected playable inventions and an emotionally complete finale.
- Mobile-first tap controls; dragging is optional enhancement.
- Reuse one stitching engine for all chapters; do not create three incompatible puzzle systems.
- All audio user-initiated, muted via visible switch; videos skippable with poster and reduced-motion fallback.
- Do not mark unverified features complete. Never fabricate test evidence.
- No secrets, unlicensed assets or uncontrolled third-party imports.

## Loop protocol
1. Identify the active loop in docs/EXECUTION_LOOPS.md.
2. Audit existing implementation and docs; note conflicts.
3. Define acceptance tests and mobile fallback.
4. Implement the smallest complete vertical slice.
5. Run available checks and inspect errors.
6. Update docs/LOOP_LOG.md with commands, results, remaining risks.
7. Commit in a reviewable change.
